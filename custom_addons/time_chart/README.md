# Модуль временных линейных диаграмм для Odoo 19

## Описание
Модуль для создания и управления временными линейными диаграммами с параметрами:
- **Time (Время)** - временная ось в секундах
- **Power (Мощность)** - мощность в ваттах
- **Resistance (Сопротивление)** - сопротивление в омах

## Возможности

### 1. Управление диаграммами
- Создание и редактирование диаграмм
- Добавление точек данных через редактируемую таблицу
- Визуализация данных в виде интерактивного графика
- Автоматическая сортировка точек по времени

### 2. Интерактивный график
- Две оси Y для отображения мощности и сопротивления
- Возможность увеличения/уменьшения масштаба
- Отображение значений при наведении курсора
- Легенда для различения параметров

### 3. PDF отчеты
- Экспорт диаграммы в PDF с графиком
- Таблица всех данных
- Статистика (минимум, максимум, среднее значение)
- Профессиональное оформление

## Установка

1. Скопируйте папку `time_chart` в директорию `addons` вашего Odoo:
   ```bash
   cp -r time_chart /path/to/odoo/addons/
   ```

2. Обновите список приложений в Odoo:
   - Перейдите в режим разработчика (Settings → Activate the developer mode)
   - Apps → Update Apps List

3. Установите модуль:
   - Apps → поиск "Time Chart Manager"
   - Нажмите "Install"

## Использование

### Создание диаграммы

1. Перейдите в меню **Временные диаграммы → Диаграммы**
2. Нажмите кнопку **Создать**
3. Заполните поля:
   - **Название диаграммы** - уникальное имя
   - **Описание** - опциональное описание
   - **Дата создания** - заполняется автоматически

### Добавление данных

1. Откройте диаграмму
2. Перейдите на вкладку **Данные**
3. Добавьте строки с параметрами:
   - **Время (сек)** - временная точка
   - **Мощность (Вт)** - значение мощности
   - **Сопротивление (Ом)** - значение сопротивления
4. Сохраните диаграмму

### Просмотр графика

1. Откройте диаграмму
2. Перейдите на вкладку **График**
3. График обновляется автоматически при изменении данных

### Создание PDF отчета

1. Откройте диаграмму
2. Нажмите кнопку **Print** в верхней панели
3. Выберите **Временная диаграмма**
4. PDF будет сгенерирован автоматически

## Технические детали

### Модели

#### time.chart
- `name` - Название диаграммы (обязательное)
- `description` - Описание
- `date_created` - Дата создания
- `line_ids` - Связь с точками данных (One2many)
- `line_count` - Вычисляемое поле: количество точек

#### time.chart.line
- `chart_id` - Ссылка на диаграмму (Many2one)
- `time` - Время в секундах
- `power` - Мощность в ваттах
- `resistance` - Сопротивление в омах
- `sequence` - Порядок сортировки

### Ограничения
- Уникальность времени для каждой диаграммы
- Все поля (time, power, resistance) обязательны для заполнения

## Примечания

### Важно для работы графиков в PDF:
- Убедитесь, что у сервера есть доступ к интернету для загрузки Chart.js
- Для лучшего качества PDF используйте wkhtmltopdf версии 0.12.6

### Рекомендации по использованию:
- Используйте упорядоченные значения времени для лучшей читабельности графика
- Для больших объемов данных рекомендуется группировать точки
- Регулярно экспортируйте важные диаграммы в PDF для архивации
