# Инструкция по установке модуля "Временные диаграммы" в Odoo 19

## Шаг 1: Копирование файлов модуля

1. Скопируйте всю папку `time_chart` в директорию `addons` вашего Odoo сервера:
   ```bash
   cp -r time_chart /путь/к/odoo/addons/
   ```

   Например:
   ```bash
   cp -r time_chart /opt/odoo/addons/
   ```

## Шаг 2: Перезапуск Odoo сервера

Перезапустите Odoo сервер для обнаружения нового модуля:

```bash
sudo systemctl restart odoo
```

Или если вы запускаете Odoo вручную:
```bash
./odoo-bin --addons-path=/путь/к/addons --db-filter=^ваша_база$
```

## Шаг 3: Обновление списка приложений

1. Откройте Odoo в браузере
2. Войдите как администратор
3. Перейдите в **Settings** (Настройки)
4. Активируйте режим разработчика:
   - Прокрутите вниз до раздела "Developer Tools"
   - Нажмите **Activate the developer mode**

5. Перейдите в **Apps** (Приложения)
6. Нажмите на кнопку меню (три точки) → **Update Apps List**
7. В появившемся диалоге нажмите **Update**

## Шаг 4: Установка модуля

1. В меню **Apps** найдите модуль через поиск:
   - Введите "Time Chart" или "Временные диаграммы"
   
2. Нажмите кнопку **Install** (Установить) на карточке модуля

3. Дождитесь завершения установки

## Шаг 5: Проверка установки

После установки в главном меню должен появиться новый пункт **"Временные диаграммы"**

1. Нажмите на него
2. Выберите **Диаграммы**
3. Если установка прошла успешно, вы увидите две демонстрационные диаграммы

## Использование модуля

### Создание новой диаграммы

1. **Временные диаграммы → Диаграммы → Создать**
2. Заполните поля:
   - **Название** - введите имя диаграммы
   - **Описание** - опционально
3. Перейдите на вкладку **Данные**
4. Добавьте точки данных:
   - **Время (сек)** - временная точка
   - **Мощность (Вт)** - значение мощности
   - **Сопротивление (Ом)** - значение сопротивления
5. **Сохранить**

### Просмотр графика

1. Откройте созданную диаграмму
2. Перейдите на вкладку **График**
3. График построится автоматически на основе введенных данных

### Экспорт в PDF

1. Откройте диаграмму
2. Нажмите кнопку **Print** (Печать) в верхней панели
3. Выберите **Временная диаграмма**
4. PDF документ откроется в новой вкладке

## Возможные проблемы и решения

### Модуль не появляется в списке приложений

**Решение:**
1. Проверьте, что папка `time_chart` находится в правильной директории `addons`
2. Проверьте права доступа к файлам:
   ```bash
   sudo chown -R odoo:odoo /путь/к/addons/time_chart
   ```
3. Перезапустите Odoo сервер
4. Обновите список приложений еще раз

### Ошибка при установке

**Решение:**
1. Проверьте логи Odoo:
   ```bash
   tail -f /var/log/odoo/odoo-server.log
   ```
2. Убедитесь, что все зависимости установлены
3. Проверьте права доступа к базе данных

### График не отображается

**Решение:**
1. Убедитесь, что у сервера есть доступ к интернету (для загрузки Chart.js)
2. Проверьте консоль браузера на наличие ошибок JavaScript
3. Очистите кэш браузера (Ctrl + Shift + R)

### PDF не генерируется

**Решение:**
1. Убедитесь, что установлен wkhtmltopdf:
   ```bash
   sudo apt-get install wkhtmltopdf
   ```
2. Проверьте версию wkhtmltopdf (рекомендуется 0.12.6)
3. Проверьте настройки в Odoo: **Settings → Technical → System Parameters**
   - Найдите параметр `web.base.url` и убедитесь, что он правильный

## Дополнительная информация

### Структура файлов модуля

```
time_chart/
├── __init__.py              # Инициализация модуля
├── __manifest__.py          # Метаданные модуля
├── models/                  # Модели данных
│   ├── __init__.py
│   └── time_chart.py
├── views/                   # Представления (XML)
│   └── time_chart_views.xml
├── reports/                 # Отчеты PDF
│   └── time_chart_report.xml
├── security/                # Права доступа
│   └── ir.model.access.csv
├── data/                    # Демо-данные
│   └── demo_data.xml
└── README.md               # Документация
```

### Требования

- Odoo 19.0
- Python 3.8+
- PostgreSQL 12+
- wkhtmltopdf 0.12.6 (для PDF)
- Доступ к интернету (для Chart.js CDN)
